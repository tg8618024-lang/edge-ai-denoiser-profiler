## 3. Caveats

1. **Hardware-Specific SIMD Acceleration**:
   - In standard NumPy on x86_64, `np.float16` matrix multiplication is software-emulated, whereas FP32 uses AVX2/MKL BLAS. To realize genuine hardware speedups for FP16 and INT8, Numba JIT, PyTorch, or ONNX Runtime should be enabled when available. The design provides automatic fallback.
2. **Dynamic Audio Jitter**:
   - Audio buffer timing depends on OS scheduler latency and soundcard driver buffer sizes (e.g. WASAPI / PortAudio). P99 latency will capture scheduler jitter, which must be accounted for in threshold assertions.
3. **Multi-Threaded UI Reads**:
   - When the web dashboard queries the rolling statistics buffer over WebSockets, snapshot reads must be guarded by a mutex lock (`threading.Lock`) to avoid reading during a concurrent write.
