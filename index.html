QUICKSTART

Up and Running in 60 Seconds

Python 3.10+ required. Works on Windows, macOS, and Linux.

1
Clone the repository
Get the full source including all models, hardware RTL, and extension files.
2
Create virtual environment
Isolates all dependencies cleanly. Compatible with pyenv, conda, and system Python.
3
Install dependencies
NumPy, FastAPI, Uvicorn, ONNX Runtime, pystoi, scipy — all listed in requirements.txt.
4
Launch the dashboard
The full testbench runs at http://127.0.0.1:8000 with WebSocket streaming.
bash · PowerShell
# 1. Clone the repository
git clone https://github.com/tg8618024-lang/edge-ai-denoiser-profiler.git
cd edge-ai-denoiser-profiler

# 2. Create & activate virtual environment
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the benchmark to verify everything works
python evaluate.py # All 8 presets should PASS, exit code 0

# 5. Launch the live dashboard
python run_dashboard.py

# → Open http://127.0.0.1:8000 in your browser 🚀
# → Keynote Deck: http://127.0.0.1:8000/presentation
# → WebGPU Engine: http://127.0.0.1:8000/webgpu

# 6. Run the full test suite (375 tests)
pytest -q
bash · Optional Advanced Workflows
# Run 7-tier component ablation study
python scripts/run_ablation.py

# Run hardware benchmarks
python benchmarks/benchmark_baseline.py
python benchmarks/benchmark_model_dsp.py

# Verify FPGA RTL numerical parity (Python simulation)
python hardware/fpga_rtl/verify_rtl_sim.py

# Start Prometheus + Grafana observability stack
docker-compose -f docs/observability/docker-compose.observability.yml up
